## 已知风险与兜底

- **微信 WKWebView blob: 长按**：WKWebView 可能不支持对 blob: URL 长按保存。若失败，可尝试让结果图改用 data URL。
- **EXIF 方向**：`createImageBitmap(file)` 默认 `from-image` 应在现代浏览器中自动纠正，但旧版 WKWebView 可能不支持。
- **开发色板**：当前输出色号为 M01-M40 示意色号，不代表真实 MARD 产品色号。
