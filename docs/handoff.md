# 拼豆图纸 MVP V0 技术交接

## 项目背景

用户有一张喜欢的图片、照片、宠物照、角色图、追星应援图或游戏头像，希望快速生成一份可以实际制作的拼豆图纸包。

当前阶段目标不是做完整平台，而是搭建一条低成本、半自动的内部生产链路，用于 MVP 调研验证。

## 阶段目标

- 快速稳定处理用户图片
- 自动或半自动生成拼豆图纸
- 降低人工调图成本
- 输出用户能直接照着拼的图纸包
- 记录每个案例的输入、输出、反馈

## V0 要做

- 本地运行或内部部署参考图纸生成工具
- 导入用户图片
- 生成至少 2-3 个候选图纸版本
- 导出图纸预览、网格图、色号清单、豆子数量
- 沉淀处理记录
- 形成标准交付包

## V0 暂不做

- 用户登录、支付、小程序
- 公开图纸库、社区、交易市场
- 自动发布小红书
- 完整后台管理系统
- 大规模存储
- AI 生图入口
- 用户在线编辑器
- 自动买豆或电商采购链路

## 推荐实现策略

```text
参考项目内部部署
+
自定义预处理脚本
+
自定义 preset 规则
+
自定义交付包模板
+
人工少量校验与修正
```

## 标准链路

```text
用户提交图片和需求
-> 记录用户需求
-> 图片预处理
-> 生成 2-3 个候选图纸
-> 人工快速选择/微调
-> 导出图纸包
-> 交付给用户
-> 记录用户反馈
```

## 最小验收标准

- 能本地运行参考工具
- 能处理 5 张测试图
- 每张图能生成至少 2 个候选版本
- 每张图能输出完整交付包
- 每张图有 metadata
- 每张图有颜色清单和总豆数
- 单张图人工处理时间记录完整
- 整体流程有 SOP
- 色号库有初步结构
- 明确记录当前无法自动化的步骤
