## 使用边界

参考项目采用 AGPL-3.0 协议。本仓库当前不复制其代码，只将其作为内部图纸生产工具和产品流程参考。

如果后续基于参考项目代码做衍生作品，需要保留版权声明，并重新评估是否需要按 AGPL-3.0 开源相关衍生代码。

## 本地启动方式

```bash
git clone https://github.com/Zippland/perler-beads.git
cd perler-beads
npm install
npm run dev
```

浏览器打开：

```text
http://localhost:3000
```

## 已知可复用能力

- 图片转拼豆图纸
- 主导色像素化
- 多品牌色号适配
- 自动颜色合并
- 背景移除
- 颜色排除与重映射
- 手动精修
- PNG 图纸导出
- 采购清单导出
- 色号映射库

## V0 验证清单

- 页面是否能本地打开
- 是否能上传 JPG/PNG
- 是否能生成 29x29、48x48、58x58、72x72 等尺寸
- 是否能切换品牌色号体系
- 是否能导出 PNG 图纸
- 是否能导出采购清单
- 透明背景是否保留
- 导出结果是否带品牌水印
- 是否支持批处理
- 是否支持命令行调用
- 操作者完成一单需要多少分钟
